# Bali Bagus Car Rental

One-page Starter Product by **Bali Bagus Dev Studio**.

## Scope
- One-page responsive website
- Fleet showcase
- Starting prices
- WhatsApp inquiry / booking CTA
- Airport transfer / private driver messaging
- FAQ
- Mobile responsive
- Premium editorial + travel visual direction

## Product position
**Starter · 1 halaman**

The website intentionally uses WhatsApp as the inquiry channel. Availability and final pricing are confirmed manually until a production booking backend is connected.
